## Limitations

- The upstream generator defines queries, not a static log dataset. The
  harness seeds synthetic selector/variant streams so the filters execute;
  it does not reproduce Loki's multi-gigabyte generated dataset.
- Log lines cover JSON, logfmt, multi-line, unicode, empty, and long
  bodies, but are identical across selectors. The comparison checks
  result shape and values, not storage throughput.
- Metric evaluation timestamps are compared at whole-millisecond
  precision, which is Loki's response precision.
- The reference Loki and ClickHouse fixtures contain only this run's
  entries. A mismatch can be a genuine engine difference or a fixture
  normalization gap; every case is listed above rather than retried.
